### Data Access
The data can be accessed at: https://drive.google.com/file/d/1u-iwnPDbe6ZK7wSFVMI-PpCKaRQ3RVmg/view
The data must be downloaded and unzipped to be used.
The average annual sea surface temperature data is derived from NOAA's 5km Daily Global Satellite Sea Surface Temperature Anomoly v3.1. The NOAA page can be found here: https://coralreefwatch.noaa.gov/product/5km/index_5km_ssta.php
The bathymetry (depth) data is derived from the General Bathymetric Chart of the Oceans (GEBCO). The page can be accessed here: https://www.gebco.net/data-products/gridded-bathymetry-data#area
The exclusive economic zones (regions) data is derived from marineregions.org, which can be accessed here: https://www.marineregions.org/eez.php
The oyster and shrimp data was sourced from SeaLifeBase. SeaLifeBase can be found here: https://www.sealifebase.ca/search.php
